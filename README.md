Tip Calculator

Application Android simple permettant de calculer un pourboire.

## Fonctionnalités

- Saisir le montant de la facture
- Choisir le pourcentage du pourboire
- Arrondir le pourboire si nécessaire
- Afficher automatiquement le montant du pourboire

## Technologies

- Kotlin
- Android Studio
- Jetpack Compose

## Lancer le projet

1. Ouvrir le projet dans Android Studio.
2. Lancer un émulateur Android ou connecter un téléphone.
3. Cliquer sur **Run**.
